# Brain View Pro (3D 知识大脑专业版)

[English](./README.md) | [简体中文](./README.zh.md)

**将您的 Obsidian 知识库化为可交互的 3D 脑图星系，内置专属刷题与深度笔记工作台。**

Brain View Pro 是专为 [Obsidian](https://obsidian.md) 打造的增强型 3D 知识图谱插件。它基于目录层级将海量笔记梳理为清晰独立的 **3D 球状星团**，彻底告别杂乱的蜘蛛网线条，并深度集成了支持**全文 Markdown 原生预览、个人做题笔记双向同步、单节点自由标色与宽屏左右分栏**的沉浸式学习卡片。

---

## ✨ 核心特色

### 1. 🪐 3D 球状星团分区 & 纯净主干放射线
- **多层级星域分布**：按文件夹层级（科目 → 核心模块 → 子考点）将全库笔记自动编排为互不穿模的 3D 球状星团。
- **智能去杂网（Anti-Cobweb）**：全景背景自动过滤海量真题之间的横向多边形蜘蛛网，呈现以考点母星为中心的纯净放射线束；点选具体单题时自动高亮其 1 级与 2 级关联真题。
- **常驻 3D 板块悬浮铭牌**：各考点球心上方常驻悬浮发光色点与题量铭牌（如 `● 片段阅读-中心理解 1489`），点击铭牌直接镜头飞入该考点。

### 2. 🎨 节点自由标色 & 7 种复习状态标签
- **7 种学习状态胶囊**：一键标记 **错题/重点** (`#ff3b5c`)、**疑点** (`#ff9f1c`)、**待复盘** (`#facc15`)、**已掌握** (`#10b981`)、**典型母题** (`#00e5ff`)、**进阶拓展** (`#c084fc`)、**归档** (`#94a3b8`)。
- **自由取色与一键恢复**：内置色彩选择器，支持任意自定义颜色或一键恢复脑区默认色。
- **3D 星图联动与搜索置顶**：被标色节点在 3D 图中自动覆盖脑区颜色并放大 `1.65x`，在搜索框（`Ctrl/Cmd + F`）中优先置顶展示。

### 3. 📖 完整 Markdown 预览 & 折叠解析交互
- **告别文字截断**：卡片内完整渲染题干、YAML 属性胶囊、公式、表格、图片与解析。
- **支持折叠块刷题对答案**：直接在悬浮框内点击展开 `> [!success]- 点击查看答案与解析` 折叠块，无需离开 3D 脑图即可刷题核对解析。
- **内链飞跃跳转**：点击卡片内的 `[[双向链接]]`，3D 镜头平滑飞跃定位到目标考点或真题。
- **源码编辑切换**：支持一键切换为 Markdown 源码编辑模式，原地修改保存全文。

### 4. 📝 专属个人笔记 / 做题批注空间
- **独立批注面板**：卡片下方（或分栏右侧）设有专属的做题思路、易错总结输入框。
- **双向实时同步**：输入内容自动防抖同步写回对应 `.md` 笔记文件末尾的 `## 📝 个人笔记` 章节。
- **自我保存锁保护**：保存笔记过程经过防抖保护，绝不打断当前阅读或重置 3D 视角。

### 5. ⤢ 大尺寸悬浮框 + 自由拖拽缩放 + 一键分栏宽屏
- **默认宽敞尺寸**：默认 `540 × 680 px`，内置滚轮与快捷键完全隔离（卡片内滚屏打字绝不误触 3D 镜头）。
- **一键分栏宽屏**：一键切换为 `860 × 720 px` 左右双栏工作台（左侧读题干与解析，右侧写个人批注）。
- **自由拖拽缩放**：按住标题栏任意拖动，拖拽双角手柄自由缩放并记忆尺寸。

### 6. 🥽 VR 与脑图 DNA 导出
- **Noda VR (Quest 3)**：一键导出 CSV，佩戴 VR 头显在虚拟现实中置身于自己的知识星系内部。
- **Digent DNA 导出**：导出记录全部神经元坐标与突触拓扑的 DNA 结构文件。

## 📥 安装方式

### 方式一：通过 Obsidian BRAT 插件安装（推荐，自动更新）
1. 在 Obsidian 社区插件市场中安装并启用 **BRAT** 插件；
2. 进入 BRAT 设置，点击 **Add Beta plugin**；
3. 输入仓库地址：`P123149P/brain-view-pro`；
4. BRAT 会自动完成安装，后续发布新版也能一键自动更新。

### 方式二：手动离线安装
1. 前往本仓库 [Releases](https://github.com/P123149P/brain-view-pro/releases) 下载 `main.js`、`manifest.json`、`styles.css` 这 3 个文件；
2. 打开您的 Obsidian 库目录，进入 `.obsidian/plugins/`，新建文件夹 `brain-view-pro`；
3. 将下载的 3 个文件复制到 `.obsidian/plugins/brain-view-pro/` 目录下；
4. 打开 Obsidian 设置 → 第三方插件 → 点击重新加载并启用 **Brain View Pro**。

## 🎮 操作快捷键

| 操作 | 快捷方式 |
|---|---|
| **旋转星系** | 鼠标左键拖拽 |
| **平移视角** | 鼠标右键拖拽 |
| **缩放视角** | 鼠标滚轮 |
| **聚焦节点/板块** | 单击节点粒子或 3D 板块铭牌 |
| **自由飞行** | `W` / `A` / `S` / `D`（前/左/后/右），`Q`（下），`E`（上） |
| **快速搜索** | `Ctrl + F` / `Cmd + F` |
| **视角复位** | 点击 **Recenter** 或按 `R` |
| **关闭卡片** | `Esc` 或点击卡片右上角 `✕` |
